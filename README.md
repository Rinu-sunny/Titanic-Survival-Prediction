# Titanic-Survival-Prediction
This project focuses on building a machine learning model to predict the survival of passengers aboard the Titanic using passenger data. The dataset contains various features such as age, sex, ticket class, fare, and family information.
#The main steps of the project include:

1.Data Cleaning and Preprocessing: Handling missing values, removing irrelevant features, encoding categorical variables, and engineering new features such as family size and whether a passenger is alone.

2.Exploratory Data Analysis (EDA): Visualizing distributions and relationships between features and survival outcomes using plots and correlation heatmaps.

3.Model Building: Training a Random Forest classifier to predict survival, optimizing model parameters to improve accuracy.

4.Evaluation: Assessing model performance using accuracy score, confusion matrix, and classification report.

The model achieves over 80% accuracy, demonstrating effective use of data preprocessing and ensemble learning techniques to predict passenger survival.
